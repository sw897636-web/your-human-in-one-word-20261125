off on everything. My word:

## Bottleneck

Every decision has to squeeze through one narrow neck: theirs.

## How it works

`main.ts` (Node 22, standard library only) writes the word to
`/output/entry.txt`. No input, no network, no randomness — every run writes
the exact same bytes.

```sh
node main.ts
cat /output/entry.txt
```
